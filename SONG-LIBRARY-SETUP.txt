CHURCHHQ - LYRICS + CHORDS LIBRARY SETUP
=========================================

1. Open your Supabase project.
2. Go to SQL Editor.
3. Open SUPABASE-LYRICS-CHORDS-LIBRARY.sql from this folder.
4. Copy the entire SQL file, paste it into Supabase, and click Run.
5. Wait for the Success message before opening the updated system.

WHAT CHANGED
------------
- The existing public.songs table is retained as the Chords Library.
- The new public.lyrics_library table stores plain lyrics for FreeShow.
- Both libraries remain under the Song Library page.
- Add, Edit, and Delete follow the existing Song Library role permissions.
- Add, Edit, and Delete actions are included in Audit Logs.
- lyrics_library is included in JSON Export and Import/Restore.
- Older ChurchHQ backups remain supported; missing lyrics_library data is
  treated as an empty list.

IMPORTANT
---------
Do not rename or remove the existing public.songs table. It is still used by
the Sunday Service song lineup and Chords Library functions.
