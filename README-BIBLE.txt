CHURCHHQ - LOCAL JSON BIBLE INSTRUCTIONS
========================================

1. Keep these items together in the same project folder:

   index.html
   app.js
   style.css
   Bible/

2. Do not rename these Bible subfolders unless you also update app.js:

   Bible/Old Testaments/
   Bible/New Testaments/

3. Upload index.html, app.js, style.css, and the complete Bible folder to the
   same GitHub repository. Keep the folder names and capital letters exact.

4. Open ChurchHQ through GitHub Pages or a local web server. Browsers may block
   JSON loading when index.html is opened directly with file://.

5. Open Editor > Bible Reading Editor, then click the Bible button. The viewer
   shows BibleGateway and My Bible beside each other on wide screens. On phones,
   they stack vertically.

6. Known unavailable source content:

   Job Chapter 41
   Psalms Chapter 93
   Acts Chapter 21
   Acts Chapter 22
   Acts 2:1

   ChurchHQ displays an unavailable warning for these entries and does not
   invent, replace, or silently skip their text.

7. Copy Chapter copies only verses available in the selected JSON chapter.
   Insert to Editor places the available chapter in the editor and returns to
   the editing view.

8. Use only Bible text that you are legally allowed to reproduce or distribute.
