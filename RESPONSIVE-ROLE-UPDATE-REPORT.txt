COJTGK SYSTEM — RESPONSIVE, MODAL & ROLE UPDATE REPORT
=====================================================

SOURCE
------
The update was created only from the user-provided COJTGK System.zip.

CHANGES
-------
1. Added a shared modal component layer for Add, Edit/Update, View, management,
   and footer actions across the application.
2. Added consistent backdrop behavior, Escape/backdrop close support, body
   scroll locking, accessible dialog attributes, and mobile bottom-sheet layout.
3. Added responsive table labeling and mobile record cards to prevent page-level
   horizontal scrolling.
4. Added mobile row-tap View behavior. The separate View control is hidden on
   mobile while Edit/Delete controls remain independently clickable.
5. Added Administrator/User member types.
6. Added a per-user, per-page View/Add/Edit/Delete permission matrix in Settings.
7. Added View-only defaults for User accounts and full access for Administrator.
8. Kept the Song Library shared, with separate View/Add/Edit/Delete permission
   enforcement and RLS policies.
9. Added a safe Supabase migration, automatic role creation for new Auth users,
   backward-compatible error handling, and an installation guide.
10. Compatibility correction: user_roles now uses user_id as its identifier and
    does not require a separate id column. New User accounts retain the legacy
    viewer role value while member_type controls the new permission matrix.
